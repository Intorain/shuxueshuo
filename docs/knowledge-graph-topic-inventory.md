# 两个专题的知识点与方法清单

本文定义两个专题的图谱节点及其内容范围，供 `site/data/knowledge/graph.json` 与专题步骤映射使用。

依据：`/1/` 30 题、`/2/` 9 题的全部路线与步骤（`practice-config`）、目录页分组说明，以及[知识图谱页面设计](knowledge-graph-pages-design.md)。括号里的数字是该步骤在题库中出现的次数。

## 1. 划分标准

图谱只设“知识点”和“方法”两种顶层节点类型。“表达式的变形方法”是“方法”的子类，不是第三种顶层类型。

| 类别 | 定义 | 例子 |
| --- | --- | --- |
| 知识点 | 概念、定理、性质、公式，或跨方法通用的判断规则；说明判断与操作的依据 | 基本不等式、不等式的性质、一元二次不等式的解法 |
| 方法 | 可执行的解题操作或策略；说明何时采用、如何执行 | 配齐次式、分离参数法、换元、配方 |

同一知识点或方法只有一个全局 ID，B、Q、M 编号仅供文档定位。topic 选择全局节点的子集，记录本专题题目、步骤与案例，不复制节点定义。

图谱只保留两类必要关系，具体连线见第 5 节：

| 方向 | 关系 | 标准 |
| --- | --- | --- |
| 知识点 → 知识点 | 前置依赖 | 当前课程中理解后者的直接学习前提，不因某条证明用到前者而连线 |
| 方法 → 知识点 | 使用 | 方法成立的核心知识依据，不包含个别题目的后续运算 |

方法之间不连线。方法组合、先后顺序与实际用到的知识记录在题目步骤中；允许节点暂时没有连线。

## 2. 专题一：基本不等式（`/1/`，人教 A 版 2.2）

### 2.1 知识点

| 编号 | 知识点 | 类型 | 题目中的步骤 | 题目 |
| --- | --- | --- | --- | --- |
| B1 | 平方的非负性及其推论：由 $(a-b)^2\ge0$ 得 $a^2+b^2\ge2ab$，等价于 $ab\le\left(\frac{a+b}2\right)^2$（$a,b\in\mathbb R$，等号当且仅当 $a=b$）；图谱短名称为“平方的非负性” | 性质 | 选不等式（3）、验证端点（2）、q02 配方后验证取等（1） | q02、q28–q30 |
| B2 | 基本不等式：$\sqrt{ab}\le\frac{a+b}2$（$a,b>0$），及变形 $a+b\ge2\sqrt{ab}$、$ab\le\left(\frac{a+b}2\right)^2$；使用条件“一正、二定、三相等”属于本知识点 | 定理 | 应用基本不等式（30）；一正：判断正负、判断两项为正、q04 转化为正项；二定：观察结构／观察和积结构（29）；三相等：验证取等（32） | 30 题 |
| B3 | 齐次式：各项次数相同；零次齐次式的值只与比值有关 | 概念 | 识别齐次结构（8） | q10–q15、q21、q22 |
| B4 | 二元对称多项式可以用两变量的和与积表示：$s=x+y$、$p=xy$ | 性质 | 识别对称结构（4）、构造对称（2） | q08、q28–q30 |
| B5 = Q9 | 不等式的性质：传递性、两边同加同减、两边同乘同除、同向相加、正数同向相乘、同号取倒数 | 性质（2.1） | 整理表达式、回到原式（q04）；转化目标（q26、q27） | q04、q07、q26、q27 |
| B6 = Q1 | 二次函数的图像与性质；本专题侧重配方后的最值判断，共用 Q1 节点 | 性质（2.3） | 求二次式的上界（2） | q01、q09 |
| B7 = Q2 | 一元二次不等式的解法；与 Q2 共用节点 | 方法性知识（2.3） | 解出范围（2）、解不等式（1） | q28–q30 |

一正、二定、三相等不单列节点，但步骤仍分别考查它们。步骤的 `tip` 指向 B2，用 `case` 说明这一步检查的是哪个条件；B2 的展示组件里分三段讲清三个条件。

q05 用到的指数运算 $2^a\cdot2^b=2^{a+b}$ 只是题目附带的运算，不立节点。

q02 的“选择平方结构”是配方操作，关联 M8，不关联 B6：配成平方后用的是平方非负，不需要二次函数的图像；它的取等步骤关联 B1。

q01、q09 消元路线最后的“检查可行性”（2）关联 Q13 边界值的可达性：消元后剩下变量的范围决定最值能不能取到。`/1/` 因此也用到 Q13 节点，与 `/2/` 共用，不另建。

#### B4 的内容范围

B4 是一个知识点，名称为“二元对称多项式可以用两变量的和与积表示”。节点内先说明交换 $x,y$ 后多项式保持不变，再讲它可以写成 $s=x+y$、$p=xy$ 的多项式，并展示常用关系：

$$
x^2+y^2=(x+y)^2-2xy=s^2-2p.
$$

上述一般结论限定为二元对称多项式，不把任意表达式都称为多项式；遇到分式时分别检查其组成及定义域。“和积换元”方法用到 B4，负责选择新变量、改写条件和目标的操作。

#### B5 的内部条目

B5 统一为“不等式的性质”一个知识点，不按每条性质拆节点。下列各字母为实数，特殊条件逐条注明：

| 条目 | 规则及条件 |
| --- | --- |
| 传递性 | $a>b$ 且 $b>c$，则 $a>c$ |
| 两边同加、同减 | $a>b$，则 $a+c>b+c$、$a-c>b-c$ |
| 两边同乘、同除 | $a>b$：$c>0$ 时 $ac>bc$、$a/c>b/c$；$c<0$ 时 $ac<bc$、$a/c<b/c$；除数不能为零，乘以零时两边相等 |
| 同向相加 | $a>b$ 且 $c>d$，则 $a+c>b+d$ |
| 正数同向相乘 | $a>b>0$ 且 $c>d>0$，则 $ac>bd$ |
| 同号取倒数 | $a>b$ 且 $ab>0$，则 $1/a<1/b$ |

非严格不等式也需按对应的非严格形式说明，不能混淆是否取等。取倒数等条目可作为性质的推论展示；易错提醒包括“同向不等式不能随意相减、相除”。步骤关联 B5 时，用本题说明标明具体条目（如负数乘除变向、同号取倒数），不因关联整个节点就认定所有性质都已练到。Q9 与 B5 共用这个节点。

### 2.2 方法节点（9 个）

M1–M9 各为一个方法节点；M2–M9 属于“表达式的变形方法”子类，节点保留短名称。

“表达式的变形方法”通过配凑、换元、消元等操作，把条件或目标改写成便于处理的形式。变形必须同步处理定义域、变量范围与等价条件；换元须保留新旧变量的对应关系，消元须保留原条件的限制，取倒数须检查非零与符号条件，并正确处理不等号方向和最值关系。

| 编号 | 方法节点 | 核心内容 | 表达式的变形方法 | 题目示例 |
| --- | --- | --- | --- | --- |
| M1 | 直接应用基本不等式 | 识别正项、定和或定积，建立界并验证取等 | 否 | q01–q05 |
| M2 | 配凑表达式 | 拆项、添减项、调整系数，构造可用的结构 | 是 | q06–q08、q16、q19、q20 |
| M3 | 配齐次式 | 根据次数关系，利用条件把整体或局部配成齐次式 | 是 | q10–q15、q21、q22 |
| M4 | 换元 | 选择整体、定义新变量，同步改写表达式与范围 | 是 | q11、q12、q14、q21、q22、q24、q25、q27 |
| M5 | 消元 | 利用条件消去一个变量，同时保留取值限制 | 是 | q01、q09、q16–q20、q30 |
| M6 | 分式分离 | 分离出整式部分和余下的分式，显露可用结构 | 是 | q16、q17、q19、q20、q23–q27、q30 |
| M7 | 和积换元 | 识别或构造对称结构，用和与积改写条件、目标 | 是 | q08、q28–q30 |
| M8 | 配方 | 配成平方项与常数之和，利用平方非负性 | 是 | q01、q02、q09 |
| M9 | 取倒数 | 在符号确定时转化目标，并正确处理不等号与最值关系 | 是 | q26、q27 |

“换元／换元法”“消元／消参”等名称共用节点；“乘 1”属于配齐次式，不另建节点。“观察结构”“验证取等”是步骤，关联实际考查的知识。配方是操作，二次函数性质是知识，分别建点。

题目示例表示路线中使用了该方法，不代表该方法与路线内所有知识都有全局连线。

q28、q29 的换元变量可为负，使用平方非负性的推论 $p\le s^2/4$；q30 的换元变量为正，同时接受 $p\le s^2/4$ 与 $s\ge2\sqrt p$ 两个等价形式。端点或取等验证检查 $(x-y)^2=0$，其中变量指和积换元所用的两个量。

#### 节点内容边界

- **Q1** 包含二次函数定义中的 $A\ne0$、配方后的顶点与最值，以及全实数上的正负判定。$A=0$ 时按剩余表达式判断是一次还是常数，不默认必为常数。“怎样配方”的操作关联方法 M8。
- **Q4** 区分全称与存在量词、比较方向、严格与非严格不等号。在最大值或最小值能取到时使用最值条件；取不到时按值域的上、下端及是否包含端点判断。例如 $x\in(0,1)$ 时 $x>0$ 恒成立，却不存在最小值，不能要求“最小值大于零”。
- **Q5** 在 Q1 基础上加入指定区间的限制，同时检查开口、顶点和区间端点。开区间可能只有取值范围的上、下端而没有对应最值；半无限区间还须检查是否无界。
- **Q6** 对 $f(t)=kt+b$，$k>0$ 递增、$k<0$ 递减；$k=0$ 为常数函数，单独说明而不称为一次函数。端点最值结论适用于有限闭区间；开区间或无界区间另看可达性和有界性。
- **Q7** 在 $x>0$ 上于 $x=\sqrt{k}$ 取最小值 $2\sqrt{k}$；在 $x<0$ 上于 $x=-\sqrt{k}$ 取最大值 $-2\sqrt{k}$。整个定义域不能笼统称为“有最低点”。Q06 的 $h(x)=-x-2/x$、$x<0$ 可令 $t=-x>0$，化为 $t+2/t$，再判断图像和最值。
- **Q8** 是一般单调性概念，Q1、Q6、Q7 是具体函数性质，不能因都讲单调性就合并。用单调性求最值是应用，不另建同名知识点。
- **Q12** 按本专题的用法命名：每个分支的结果先与分支前提取交集，再把可行分支取并集；几个条件要同时成立时取交集。原名“集合的交集与并集”，2026-10-04 改名，节点 ID 不变；学生在这些步骤里卡住的是怎样合并，而不是集合运算本身。以后需要教材意义上的集合运算时另建节点，作为它的前提。
- **Q13** 说明边界能否取到；“代回原式检验”是操作步骤，涉及恒成立或存在成立时同时关联 Q4。区间内一个反例可否定恒成立，单点成立不能证明恒成立；不能只凭原题不等号是否带等号决定参数边界是否包含。

#### Q1 的全实数正负判定

设 $f(x)=Ax^2+Bx+C$，$A\ne0$，$\Delta=B^2-4AC$。以下结论是 Q1 内“图像与横轴的位置关系”的应用，不单设知识点：

| 对所有实数 $x$ 的要求 | 等价条件 |
| --- | --- |
| $f(x)>0$ | $A>0$ 且 $\Delta<0$ |
| $f(x)\ge0$ | $A>0$ 且 $\Delta\le0$ |
| $f(x)<0$ | $A<0$ 且 $\Delta<0$ |
| $f(x)\le0$ | $A<0$ 且 $\Delta\le0$ |

本专题用 Q1 建立开口与判别式条件；后续若需解一元二次不等式，再在题目步骤中关联 Q2。$A=0$ 时不是二次函数，不能直接套用本表。题目的“判断图像位置”“建立判别式条件”步骤均关联 Q1。

### 3.2 方法范围

以下四种方法均为全局节点，可跨专题复用，名称不加专题前缀。“一元二次不等式应用”是使用场景，不是方法子类。判别式法也用于实根与交点判断；其余方法可用于其他函数的最值、方程有解等问题。

### 3.3 一元二次不等式应用中的方法（4 种）

| 方法 | 本专题的适用判断 | 核心操作 | 题目 |
| --- | --- | --- | --- |
| 判别式法 | 判断关于自变量的二次式在全体实数上的符号；先排查二次项系数为零 | 结合开口与判别式建立条件 | Q01–Q03 |
| 区间最值法 | 已转化为函数取值要求，且能分析指定区间的最值或值域 | 比较顶点与区间位置，检查边界可达性 | Q04–Q07 |
| 分离参数法 | 能等价分离参数，且分离后更便于研究值域 | 将参数表达式单列一侧，处理乘除时的符号与零值 | Q01、Q04–Q07 |
| 更换主元法 | 更换研究变量后结构更简单，且新主元的范围和量词明确 | 固定原主元，把另一变量作为自变量研究 | Q08、Q09 |

## 5. 必要连线
