# 公共知识图谱替换计划

日期：2026-10-13。状态：阶段 1、2 已实现并完成验收；新图谱与教学关联在 `/knowledge-next/` 预览，正式入口尚未替换。

设计依据：[高中数学公共知识图谱设计](public-knowledge-graph-ontology-design.md)。本文安排实施顺序与验收，不重复维护节点定义和完整关系清单。

阶段 1 的原稿格式、构建命令及验收结果见[交付与维护说明](public-knowledge-graph-stage1.md)。

阶段 2 的关联结构、小题去向、预览入口及阶段 3 交接见[教学内容迁移说明](public-knowledge-graph-stage2.md)。

## 1. 范围与前提

以新的八类节点模型替代现有公共知识图谱。第一阶段交付新图谱网页和所有节点的详情页，先审阅公共内容，再调整题目关联、数据库与发布流程。

- 首批范围为人教 A 版必修第一册第二章 2.1–2.3、现有基本不等式和一元二次不等式专题，以及已讨论的两份补充练习；暂不补初中知识节点。
- 现有图谱有 27 个节点、两种节点类型、8 条边，关联两个专题的 39 道整题。页面、生成器和发布校验均需适配新模型。
- 上一次提交尚未部署服务器，可在完成适配后集中发布新结构；实施发布前核对生产实际版本。
- **本地旧练习记录无需保留。** 实现阶段可以清理图谱相关练习记录及派生状态，重新生成测试数据；不安排旧练习记录迁移或掌握状态继承。清理范围限定在相关学习数据，不重置整个数据库。
- 日常手动测试继续使用网站 `127.0.0.1:8779`、数据库 `127.0.0.1:5432/product` 和现有固定数据目录。

## 2. 实施阶段

| 阶段 | 工作内容 | 验收结果 |
| --- | --- | --- |
| 1. 新公共图谱与详情页 | 整理八类节点的数据与关系，实现图谱展示、搜索、筛选和各类详情页 | 可以完整浏览首批节点、关系与教学内容，逐页审阅 |
| 2. 现有教学内容关联迁移 | 重新关联 39 道题的路线、步骤、图解、小题，处理旧节点的复用、拆分与合并 | 题页提示、专题入口及节点关联准确，没有失效引用 |
| 3. 数据库与发布适配 | 支持新节点和关系类型，调整公共内容导入、接口及校验；清理并重建本地相关练习测试数据 | 新数据可重复导入，校验失败整批回滚，新练习能正确关联节点 |
| 4. 联调与正式替换 | 验证页面、练习记录、发布流程及缓存更新，统一切换入口 | 新图谱正式替代旧图谱，静态页面与服务端内容一致 |

个人图谱的评估范围、状态规则与显示方式，在公共图谱确认后单独设计。涉及个人状态的正式接入，以该设计为依据。

## 3. 第一阶段：公共图谱与详情页

### 3.1 节点与内容

按当前清单预计 62 个节点，整理时按公共身份去重。

| 节点类型 | 数量 | 详情页主要内容 |
| --- | ---: | --- |
| 教材 | 1 | 教材信息、章节目录 |
| 章 | 1 | 本章说明、节目录、按节汇总的内容范围 |
| 节 | 3 | 学习内容、直接包含与拓展的节点 |
| 知识点 | 13 | 定义、表达形式、性质、成立条件、图解及内部条目 |
| 技能 | 20 | 输入、输出、适用条件、操作说明、示例、数学依据 |
| 方法 | 13 | 适用任务、解题路径、调用的技能与子方法、判断分支 |
| 题型 | 9 | 核心结构、条件与目标、涉及的知识点、候选方法及例题 |
| 判断规则 | 2 | 判断所需信息、各分支条件、选择的方法或技能 |

两个判断规则节点分别为“含参一元二次不等式的选法判断”和“区间求值技能选择”；所属子类分别为选法规则、步骤选择规则，顶层类型仍统一为判断规则。

节点 ID 和知识点内部条目 ID 保持稳定。已有节点含义相同时优先复用身份，语义不同的对象分别建点。例如“配方”作为技能，“配方求最值法”作为方法，分别记录。

已有图解经内容核对后复用；新节点先提供完整的文字、公式和示例，按需增加交互图解。配方、因式分解的操作说明按已确认设计纳入技能正文。

### 3.2 内容来源与生成

- 公共节点、关系及正文原稿继续由文件维护；按类型组织内容，通过共享模板生成详情页。
- 图谱、详情页和后续数据库导入共用同一份内容原稿；数据库作为发布后的查询数据，不独立编辑公共内容。
- 图解 JS、样式等作为展示资源关联节点；节点详情页不要求都有独有的图解 JS。
- 方法保存有序的路径描述、调用与分支。图谱中的“调用”连线用于表达关联，详情页的步骤顺序来自方法路径描述。
- 第一阶段的方法和规则用于教学展示；可执行契约、自动匹配与计算能力另行验证。

### 3.3 图谱网页

三个视图使用同一份图谱数据。

| 视图 | 展示内容 |
| --- | --- |
| 章节视图 | 教材 → 章 → 节，以及本节包含、拓展的内容 |
| 知识关系视图 | 知识点的必要前置关系、技能使用的数学依据，以及题型涉及的知识 |
| 解题关系视图 | 题型 → 选法规则／方法 → 步骤选择规则／技能／子方法 |

第一版建议以二维有向图为主，默认展示选中节或节点的相关范围。支持按名称搜索、按类型和关系筛选，用箭头及关系名称说明连线含义。

点击节点查看摘要并进入详情页；详情页支持返回图谱并定位原节点。方法详情页展示有序路径和条件分支，知识点内部条目提供可直接定位的链接。

实现期间使用 `/knowledge-next/` 预览入口和新数据，完成后统一到 `/knowledge/` 并移除临时入口。

### 3.4 分批交付与验收

| 批次 | 交付 | 验收重点 |
| --- | --- | --- |
| 1A. 数据与模板样例 | 节点身份清单、关系数据、每种类型各一个完整详情页、图谱样例 | 类型边界、关系含义、正文结构和导航方式 |
| 1B. 完整内容与页面 | 全部节点正文、关系、详情页及三个图谱视图 | 数学内容完整，跨节对象共用节点，相关页面互相可达 |
| 1C. 浏览器验收 | 桌面及移动端页面审阅、生成器与数据校验 | 公式、图解、布局、搜索、筛选、定位和链接均正常 |

第一阶段完成标准：

- 每个节点都有实质内容和可直接访问的详情页，公共内容无需登录即可浏览。
- 教材、章、节的层级正确，章只直接关联节；章的数学内容范围由节汇总。
- 题型、方法、技能和判断规则按设计文档连接，判断规则不连接知识点。
- 方法的知识依据通过实际调用的技能和子方法汇总；方法间只登记实际调用关系。
- 节点 ID、内部条目引用、资源引用和连线端点合法，知识前置关系无环。
- 图谱与详情页的关系、名称和正文保持一致；自动生成结果可重复校验。

## 4. 后续关联、数据与发布

### 4.1 教学内容关联

已覆盖 39 道题、50 条路线、259 个步骤、219 个提示分支；新增二次函数最值法后共有 67 个公共节点。新关联只在 `site/data/knowledge-next/topics/` 维护，题页通过 `?knowledge=next` 读取，不复制课程 HTML、选项或判定规则。

180 道旧小题全部登记去向：177 道有效题按主要考查对象归入 29 个节点，3 道没有对应公共节点的集合交并题保留原稿并暂时停用；16 个节点达到五题数量要求。本阶段不开放新小题作答，题干、选项和答案保存在服务端新原稿目录。

预览不初始化记录器、学习标记或导师，不提交作答 API。正式题页默认仍使用旧关联；数据库及既有记录接口留在阶段 3 适配。旧新身份清单用于内容迁移，不继承旧成绩。

### 4.2 数据库与接口

适配公共节点、内部条目、关系及教学内容引用的导入与查询，建立八类节点和关系端点的校验。正文导出不再假定每个节点必须有独立图解模块。

本地旧练习记录及派生状态可清理，使用新节点与题目关联生成新的测试记录。数据库结构更新采用可重复执行的发布流程，统一在既定本地实例上完成适配。

验证公共内容重复导入、非法引用拒绝、事务回滚，以及新练习的规则提交、提示展示、导师对话与刷新恢复；导师链路包含真实 LLM 对话验收。

### 4.3 正式切换

核对生产已部署版本，构建并验证管理与 API 镜像，演练数据库结构更新和公共内容导入。静态页面、图解、题页、教师数据与服务端导入内容配套发布，更新完整缓存引用链。

统一图谱入口与详情页链接，清理失效页面和引用，并同步更新旧页面设计及维护文档，明确新设计为公共图谱的维护依据。

## 5. 后续单独设计

- 个人知识图谱：哪些节点参与评估、如何根据新练习记录更新状态及展示依据。
- 图计算与求解：题型识别、规则判断、方法选择、可执行 Plan 和 LLM 组合求解，通过具体题目与单元测试逐步验证。

以上事项在公共图谱内容确认后展开，不作为第一阶段页面验收的前置条件。
